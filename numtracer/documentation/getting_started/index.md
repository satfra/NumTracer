# Getting Started

assumes, how to install and consume it, and the mental model the tutorials build on. If you want
to trace a network from your own theory (not the QCD/fRG examples), read
[Scope & conventions](scope-and-conventions.md) and
[Bring your own network](bring-your-own-network.md) first — they are the general on-ramp. The
[Glossary](glossary.md) defines every term the rest of the guide uses. Coming from FORM? Start with
[Coming from FORM](coming-from-form.md).
